# Панель тестового прогона /test — дизайн

Дата: 2026-09-30. Решения владельца: панель /test (для владельца, админов с полным доступом и аккаунтов из списка предпрода); режимы скорости: реальное время + пометки, ускоренно 10 с, «следующий пост сейчас»; админы с полным доступом могут всё, кроме «Выпустить в продакшен»; пометки «пришло бы через…» — только тестировщикам и только при включённом предпроде, в продакшене их нет ни у кого.

## Тестировщик
`tester_ids(settings, admin_ids, db)` = владельцы (ADMIN_IDS) ∪ viewers с ролью admin ∪ `preprod_user_ids`. Предпрод (`allowed_user_ids`) пускает именно их (раньше — без админов с ролью admin).

## Панель
`/test` и кнопка «🧪 Тестовый прогон» в главном меню админки (`t:open`). Остальным не отвечает. Показывает режим (🐢 реальное время / ⚡ ускоренно), состояние предпрода, прогресс по постам (✅ отправлен с датой МСК, ⏳ ближайший с датой и «через …», · в очереди «через X после предыдущего», ⏭/❌ с причиной). Кнопки: 🔄 Начать заново (`users.reset` + приветствие), ⏭ Сразу к прогреву (`deliver_material_once`, без личной ссылки), ⏩ Следующий пост сейчас (`skip_wait` + `Scheduler.run_user`), ⚡ Ускоренно / 🐢 Реальное время (`FunnelRepo.set_fast`), 🔃 Обновить.

## Скорость
В ускоренном режиме между постами 10 секунд; пока у кого-то ожидает шаг с `funnel_fast=1`, планировщик проверяет очередь каждые 10 секунд вместо 60 (`FunnelRepo.has_fast_pending`).

## Права
Админ с ролью admin: добавлять/очищать тестовые аккаунты, включать предпрод, панель, расписание, отзыв. «Выпустить в продакшен» (`a:pre:off`) — только владелец.

## Вход из Прогрева
Кнопка «Прогнать на себе» заменена на «🧪 Тестовый прогон». Команды `/test` добавляются в меню команд тестировщиков при /start.
